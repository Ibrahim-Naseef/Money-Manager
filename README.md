# Paisa — personal budgeting app (mobile PWA, 3D UI)
Money Architecture: Burn, Runway, Build, Play · Survive / Protect / Grow / Live.
- 3D bar stage (drag to rotate, tap a bar), 3D runway ring, tilting glass cards. Built with React Three Fiber + Drei.
- Data is stored on-device in IndexedDB (Dexie). Use Accounts → Backup / Restore.

    npm install
    npm run dev

Deploy: push to GitHub → Vercel → Import → Deploy (Vite auto-detected, no env vars).
